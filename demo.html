Embed AI Chat on Any Website

Drop two lines of JavaScript into any site. Your visitors get a fully working AI chatbot that downloads the model once and runs entirely in their browser — no backend, no API keys, no bills.

One Snippet. Any Website.

Paste these two tags anywhere in your HTML and you're done.

your-website.html 
<!-- Step 1: Configure the chatbot (optional) -->
<script>
  window.BotConfig = {
    modelId:      'onnx-community/SmolLM2-135M-Instruct-ONNX',
    botName:      'Aria',
    accentColor:  '#6366f1',
    greeting:     'Hi! How can I help you today?',
    systemPrompt: 'You are a helpful assistant for Acme Corp.',
    workerUrl:    'https://cdn.yourdomain.com/chat-worker.js',
  };
</script>

<!-- Step 2: Load the widget (async — doesn't slow your page) -->
<script src="https://cdn.yourdomain.com/chatbot-widget.js" async></script>

Why it works this way

🧠

Runs Entirely In-Browser

Transformers.js loads a quantised ONNX model into WebAssembly. Zero server calls happen during inference — every token is computed on the visitor's own device.

💾

Permanent Browser Cache

The ~90–140 MB model file downloads once and is stored in the browser's Cache Storage API forever. Every subsequent visit — and every other site using the same model — loads in under a second.

⚡

Web Worker Offloading

All inference runs in a dedicated Web Worker so the host page never stutters, even during long generation runs. Tokens stream back token-by-token for a fluid chat feel.

🔒

Privacy by Default

User conversations never leave the device. There is no backend logging, no data pipeline, and no third-party API calls during chat. Perfect for GDPR-conscious deployments.

🎨

Fully Customisable

Configure the accent colour, bot name, greeting, and system prompt from a simple window.BotConfig object — no build step required.

💸

Zero Ongoing Cost

No GPU bills. No API usage charges. Host the two JS files on any static CDN (Cloudflare Pages, GitHub Pages, Vercel) for a few cents per month.

Deploy in 3 Steps

1

Host the two JS files on a CDN

Upload chatbot-widget.js and chat-worker.js to Cloudflare Pages, Vercel, or any static host. Note the public URLs.

2

Configure BotConfig

Set workerUrl to the absolute URL of your hosted chat-worker.js. Optionally override botName, accentColor, and systemPrompt.

3

Paste the snippet & ship

Drop the two <script> tags before </body> on any page. The widget appears instantly; the AI model loads lazily the first time a visitor opens the chat.
